# Milvus Vector Database

[Milvus](https://milvus.io/) is a high performance vector database. In this project we will tryout that database
with and existing dataset.


## Create Python Environment
Create the python environment with the pyproject.toml:
```bash
# Run the following command from anywhere within the milvus_vector_database project
pixi install
```

Otherwise, you can also simply start running a script with for example
```bash
pixi run python scripts/load_glove_100_angular.py
```
This will automatically create the python environment as well.
